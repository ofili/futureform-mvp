# User Guide

## Welcome to FutureForm

FutureForm is a trust assessment platform designed to help organizations evaluate partners, vendors, and stakeholders across multiple dimensions of trustworthiness.

## Getting Started

### Creating Your Account

1. Navigate to the registration page
2. Fill in your details:
   - Email address
   - Password (minimum 8 characters)
   - First and last name
   - Job title and department
3. Click "Register"
4. Check your email for verification link
5. Click the verification link to activate your account

### Creating Your Organization

After registration, you'll be prompted to create or join an organization:

1. **Create New Organization:**
   - Organization name
   - Type (Government, Private Sector, NGO, etc.)
   - Sector focus
   - Region and country
   - Relationship stage

2. **Join Existing Organization:**
   - Enter the invitation code sent by your organization admin

## Dashboard Overview

Your dashboard provides a quick overview of:

- **Active Projects**: Projects you're currently working on
- **Pending Assessments**: Assessments awaiting your input
- **Recent Activity**: Latest updates across your projects
- **Credit Balance**: Available assessment credits
- **Team Members**: Colleagues in your organization

## Managing Projects

### Creating a Project

1. Click "New Project" from the dashboard
2. Fill in project details:
   - **Name**: Descriptive project name
   - **Type**: Select assessment type
     - Pre-investment due diligence
     - Vendor selection/procurement
     - Portfolio monitoring
     - Governance audit
     - Multi-stakeholder alignment
   - **Sector**: Industry sector
   - **Region & Country**: Geographic location
   - **Objectives**: Project goals and objectives

3. Click "Create Project"

### Project Types Explained

**Pre-investment Due Diligence**
- Evaluate potential investment partners
- Assess financial and operational risks
- Verify claims and capabilities

**Vendor Selection/Procurement**
- Compare multiple vendors
- Assess technical capabilities
- Evaluate delivery track record

**Portfolio Monitoring**
- Monitor existing partners
- Track performance over time
- Identify emerging risks

**Governance Audit**
- Assess governance structures
- Evaluate compliance
- Review decision-making processes

**Multi-stakeholder Alignment**
- Facilitate stakeholder engagement
- Build consensus
- Align expectations

## Creating Assessments

### Step 1: Select Partner

1. Search for existing partners in the global registry
2. Or create a new partner:
   - Legal name
   - Website
   - Sector and country
   - Contact information

### Step 2: Configure Assessment

- **Assessment Type**: Due diligence, procurement, etc.
- **Depth**: Quick, Standard, or Deep
  - **Quick**: 20-30 questions, 30-45 minutes
  - **Standard**: 40-60 questions, 1-2 hours
  - **Deep**: 80-100 questions, 3-4 hours
- **Deadline**: Response deadline
- **Respondents**: Invite partner contacts

### Step 3: AI Question Selection

FutureForm's AI engine selects relevant questions based on:
- Project type and sector
- Partner characteristics
- Assessment depth
- Historical data

### Step 4: Send Invitations

- Partner admin receives email invitation
- Invitation includes unique assessment link
- Respondents can save progress and return later

## Responding to Assessments

If you've been invited to complete an assessment:

1. Click the invitation link in your email
2. Review the assessment overview
3. Answer questions across domains:
   - **Governance**: Leadership, decision-making
   - **Financial**: Financial health, transparency
   - **Operational**: Processes, capabilities
   - **Technical**: Technology, innovation
   - **Social**: Impact, stakeholder engagement
   - **Environmental**: Sustainability practices

4. Upload supporting evidence:
   - Documents (PDF, Word, Excel)
   - Images (JPG, PNG)
   - Maximum 10MB per file

5. Save progress or submit when complete

## Understanding Assessment Results

### Overall Score
- **0-40**: High Risk - Significant concerns identified
- **41-60**: Medium Risk - Some concerns, requires attention
- **61-80**: Low Risk - Generally trustworthy with minor issues
- **81-100**: Very Low Risk - Highly trustworthy

### Domain Scores
Each domain is scored separately:
- Governance
- Financial
- Operational
- Technical
- Social
- Environmental

### Confidence Level
Indicates the reliability of the assessment:
- **High (80-100%)**: Comprehensive evidence provided
- **Medium (60-79%)**: Adequate evidence, some gaps
- **Low (0-59%)**: Limited evidence, significant gaps

### Red Flags
Critical issues that require immediate attention:
- **Critical**: Severe risk, immediate action required
- **High**: Significant concern, needs investigation
- **Medium**: Moderate concern, monitor closely
- **Low**: Minor issue, note for future reference

## Team Collaboration

### Inviting Team Members

1. Go to Project → Team
2. Click "Invite Member"
3. Enter email address
4. Select role:
   - **Project Admin**: Full project control
   - **Reviewer**: Review and approve responses
   - **Domain Expert**: Provide expertise in specific areas
   - **Observer**: View-only access

5. Select domain access (if applicable)
6. Send invitation

### Roles & Permissions

**Organization Owner**
- Full organization control
- Manage billing and subscriptions
- Add/remove members
- Access all projects

**Organization Admin**
- Manage organization settings
- Invite members
- Create projects
- View all assessments

**Member**
- Create projects
- Manage own projects
- Collaborate on shared projects

**Reviewer**
- Review assessment responses
- Request clarifications
- Approve/reject responses

**Domain Expert**
- Provide expertise in specific domains
- Review domain-specific questions
- Validate evidence

**Observer**
- View-only access
- Cannot edit or submit

## Managing Credits

### Understanding Credits

- Each assessment consumes credits
- Credit cost varies by assessment depth:
  - Quick: 5 credits
  - Standard: 10 credits
  - Deep: 20 credits

### Purchasing Credits

1. Go to Dashboard → Credits
2. Select a credit package:
   - Small: 50 credits
   - Medium: 100 credits
   - Large: 250 credits
   - Enterprise: Custom

3. Click "Purchase"
4. Complete payment via Flutterwave
5. Credits added immediately upon payment

### Subscription Plans

**Free Tier**
- 10 credits/month
- Basic features
- Community support

**Professional**
- 100 credits/month
- Advanced features
- Priority support
- Team collaboration

**Enterprise**
- Unlimited credits
- Custom features
- Dedicated support
- API access

## Best Practices

### Creating Effective Assessments

1. **Be Specific**: Clearly define assessment objectives
2. **Choose Appropriate Depth**: Match depth to decision importance
3. **Set Realistic Deadlines**: Allow adequate response time
4. **Invite Right People**: Include stakeholders with relevant knowledge
5. **Provide Context**: Share project background with respondents

### Responding to Assessments

1. **Be Honest**: Provide accurate, truthful responses
2. **Provide Evidence**: Upload supporting documents
3. **Be Comprehensive**: Answer all questions thoroughly
4. **Ask for Clarification**: If questions are unclear
5. **Meet Deadlines**: Submit on time or request extension

### Managing Projects

1. **Regular Reviews**: Monitor assessment progress
2. **Team Communication**: Keep team informed
3. **Document Decisions**: Record rationale for key decisions
4. **Track Actions**: Follow up on identified issues
5. **Archive Completed**: Archive old projects for reference

## Frequently Asked Questions

**Q: How many assessments can I create?**
A: Unlimited, subject to available credits.

**Q: Can I edit an assessment after sending?**
A: Yes, but only before responses are submitted.

**Q: How long do assessments take to complete?**
A: Depends on depth - Quick (30-45 min), Standard (1-2 hours), Deep (3-4 hours).

**Q: Can I export assessment results?**
A: Yes, export as PDF from the assessment page.

**Q: What file types can I upload as evidence?**
A: PDF, Word, Excel, images (JPG, PNG). Max 10MB per file.

**Q: Can I invite external partners?**
A: Yes, they'll receive an email invitation with access link.

**Q: How do I upgrade my subscription?**
A: Go to Dashboard → Credits → Upgrade Plan.

**Q: Is there a mobile app?**
A: Not yet, but the web app is mobile-responsive.
