# FutureForm MVP - Frontend Documentation

## Overview

The FutureForm MVP frontend is built using React and TypeScript, leveraging Next.js for server-side rendering and routing. This application aims to provide a seamless user experience for interacting with the FutureForm platform, focusing on trust assessments and partner evaluations.

## Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm (version 6 or higher) or Yarn

### Installation

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/FutureForm-MVP.git
   ```

2. Navigate to the frontend directory:
   ```
   cd FutureForm-MVP/frontend
   ```

3. Install the dependencies:
   ```
   npm install
   ```
   or
   ```
   yarn install
   ```

### Running the Application

To start the development server, run:
```
npm run dev
```
or
```
yarn dev
```

The application will be available at `http://localhost:3000`.

### Building for Production

To create an optimized production build, run:
```
npm run build
```
or
```
yarn build
```

To start the production server, run:
```
npm start
```
or
```
yarn start
```

## Folder Structure

- **src/**: Contains the main application source code.
  - **components/**: Reusable React components.
  - **pages/**: Next.js pages for routing.
  - **styles/**: Global CSS styles.
  - **utils/**: Utility functions for API calls and other helpers.
  - **App.tsx**: Main application component.

- **public/**: Static files such as images and icons.

- **package.json**: Lists dependencies and scripts for the frontend project.

- **tsconfig.json**: TypeScript configuration file.
